# רשימת איסוף תמונות

שלוש קטגוריות מהפיילוט מחכות לתמונות שאתה אוסף. קטגוריה נפתחת במשחק רק כשיש לה **תמונה לכל 30 הפריטים** (כדי שדו־קרב ארוך לא ייגמר בלי תמונות).

## איך מוסיפים
1. שומרים כל תמונה בדיוק בשם שבטבלה (למשל `snacks-1.jpg`). מותר jpg / png / webp.
2. מניחים אותה בתיקייה שמופיעה מעל הטבלה (למשל `mobile/assets/items/snacks/`).
3. גודל: עד 600KB לתמונה (רצוי בערך 500 פיקסלים רוחב).
4. אומרים לי "הוספתי תמונות" – ואני אחבר, אבדוק ואשמור.
